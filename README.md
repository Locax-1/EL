# 日历记账网页

这是一个纯前端静态网页，实现了：

- 注册、登录
- 当前月份日历
- 日期背景从近白色渐变到粉色
- 当天日期加粗并放大
- 点击日期后在右侧记账
- 添加“类型 / 金额”记录
- 输入不足时提示保存失败
- 用户图标退出登录
- 历史查询：从当前月份倒序显示到 1 月
- 数据使用浏览器 localStorage 保存

## 从零运行步骤

1. 新建一个文件夹，例如 `accounting_calendar_web`
2. 在文件夹中新建三个文件：
   - `index.html`
   - `style.css`
   - `script.js`
3. 将对应代码复制进去
4. 双击打开 `index.html`
5. 先注册账号和密码，再登录使用

## 文件说明

- `index.html`：页面结构
- `style.css`：页面样式
- `script.js`：页面交互和本地数据保存逻辑
